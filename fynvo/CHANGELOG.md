# Fynvo Add-on Changelog

## v1.9.0 - Recurring Expense Management, Workflow Completion & Regression Fixes

- Fixes Recurring Expense edit/save failures and scopes failed-save errors so they do not follow the user to Cards or Categories.
- Closes the expense action menu before Edit and Mark as Paid modals open on mobile and desktop.
- Adds explicit automatic-payment handling, independent of Payment Method, with idempotent scheduled occurrence processing.
- Completes recurring fields for Card/Account relationships, fixed/variable amounts, Payee/Merchant, End Date and reminders.
- Makes Category integrity warnings actionable and reconciles the headline issue count with all underlying issue classes.
- Preserves the v1.8.0 responsive visual baseline and existing financial data.
